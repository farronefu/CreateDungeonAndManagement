# v0.5 勇者の差し替えと整理

2026-09-14。新しい青い鎧の勇者へ統一し、移動8コマと専用アイコンを導入しました。追加モーションは新勇者の仮ポーズでつなぎ、カタログから差し替えられます。

## 整理したもの

- 未使用PNG9枚と対応するインポート設定を削除：初期 actors.png・tiles.png、旧勇者の beginner-hero-32x32・hero-motions-v2・hero-attack-4directions・hero-attack-impact・hero-attack-wide-48・hero-walk-4directions・hero-walk-grounded-32。
- 旧パーティクル配列・更新・描画、未使用アトラス読み込み、未使用描画ラッパーと画面保存フラグを削除。現在のイベント演出と画面保存機能は維持。
- 廃止済みの動的拡大処理を削除し、静止倍率に統一。
- 旧画像生成・ダウンロード処理 tools/make_assets.py を削除。使用中の効果音はネット接続不要の tools/build_sounds.py で再生成できます。
- READMEと素材交換手順を現仕様へ更新。過去版の文書と画面は開発記録として残しています。

使用中の魔物・地形・地上背景・フォント・ライセンス・効果音、将来の複数勇者用APIは残しています。生態系や戦闘バランスは変更していません。ユーザーの原本と過去の配布版は削除していません。

## 検証

ロジック54項目、描画設定13項目、勇者48項目、合成Joypadによる画面遷移14項目、合計129項目すべて成功。ゲーム画面で勇者とアイコンのサイズを確認し、旧素材への実行時参照がないことを確認しました。画面は docs/images/v05/ に保存しています。

物理コントローラーによる実機操作の検証は未実施です。攻撃・喜び・見回し・死亡の専用アニメーションは追加素材待ちです。
