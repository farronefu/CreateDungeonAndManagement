# キャラクター画像の差し替え（v0.5.3）

設定は `assets/characters/catalog.json`。PNGを置き換えるか `texture` を変更し、Godotで再インポートしてWindowsビルドを出力してください。配布EXEの横にPNGを置くだけでは変わりません。

## 現在の勇者

- 移動：ユーザー自作 `hero-walk-nocape-40-v1.png`。320×160、1コマ40×40、横8コマ。上から下・上・左・右。
- 足元 `anchor=[20,38]`、固定倍率 `scale=1.25`。絵の高さは約42pxで、40pxのブロックより少し大きい表示です。攻撃は下記の専用シートを等倍で表示します。
- 8fps、1周期1秒。1マスの移動時間も1秒。カメラは自動追従せず、LBで現在位置へ切り替えます。
- HUDと到来画面のアイコン：ユーザーの `1st_front.png` を `hero-portrait.png` として保存。1254×1254の原画を保持し、専用の足元と倍率で表示します。
- 見回し・喜び・死亡の専用画像は準備中です。現在は新勇者の静止ポーズを使用します。方向別攻撃の向き、斬撃・効果音、分岐での停止、捕獲後の帰還は維持しています。死亡時は仮表示をフェードさせ、骨へ切り替えます。

旧勇者の画像は使用しません。新しい素材のピクセル・透過情報は加工せず保存しています。

## 追加シートの設定

| 項目 | 内容 |
| --- | --- |
| texture | res://から始まるPNGのパス |
| cell | 透明な余白も含めた1コマの幅・高さ |
| anchor | コマ内の足元位置 |
| scale | 固定の表示倍率。素材の実寸に合わせて指定 |
| animations | アクション名に対応する横並びのコマ列 |
| row / frames / fps | 行番号（0から）・コマ数・1秒あたりのコマ数 |
| loop | falseで末尾のコマを保持 |
| placeholder | 専用絵が未完成の場合true。完成した動作では削除する |
| icon_scale | HUD・到来画面のアイコンだけに適用する倍率 |
| marker_y | 勇者の頭上マーカーの高さ |

各アニメーションに `texture`、`cell`、`anchor`、`scale` を指定すると、その動作だけ別のシート・コマサイズを使用できます。未指定ならキャラクター共通設定を使用します。大きな攻撃シートでも、体の高さと足元が移動時に合う倍率を指定してください。

勇者の動作名は `move_down/up/left/right`、`attack_down/up/left/right`、`look`、`celebrate`、`death`。`portrait` はアイコン専用、`bones` を追加すると既存の骨描画を差し替えられます。通常の生物は `idle`、`move`、`attack`、`birth` に対応します。

現在の攻撃時間は8/14秒、命中は4/14秒、見回し0.6秒、喜び0.7秒、死亡から骨への切替0.85秒です。コマ数やfpsだけを変更しても戦闘側の時間は自動では変わりません。専用シート導入時は命中コマとこれらの時間も確認してください。

種類のキーは `sprout`（灯苔）、`beetle`（琥珀虫）、`warden`（石角）、`egg`、`knight`（戦士）、`healer`（回復役）、`heart`（主）。灯苔はユーザー自作 `moss-microbe-32x32.png`、未登録の種類は既存の仮絵アトラスを使用します。

差し替え後は4方向、足元、アイコン、攻撃、死亡から骨への切替を実画面で確認してください。読み込めないパスでは代替の絵が表示されるため、起動できるだけでは差し替え成功と判断できません。

背面の原画 `1st_back.png` は方向・デザインの参考です。ゲーム内の背面歩行は移動シート2行目を使用します。

## v0.5.3 攻撃シート

`hero-attack-nocape-60-v3.png` は360×240、60×60の6コマ×4方向（下・上・左・右）。攻撃だけscale=1、anchor=[30,48]で表示します。透明余白を含めて60×60pxで、体自体を60pxへ引き伸ばしません。10.5fpsで従来の攻撃時間8/14秒に合わせ、4/14秒の命中が4コマ目の振り抜きに重なります。歩行は従来の倍率1.25のままです。
