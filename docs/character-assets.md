# キャラクター画像の差し替え

v0.4ではユーザー自作の透過PNGを加工せず保存しています。灯苔は `assets/characters/moss-microbe-32x32.png`、戦士は `hero-motions-v2.png` を使用します。その他の種類は既存の仮絵です。

設定は `assets/characters/catalog.json`。PNGを同じ名前で置き換えるか、種類ごとの `texture` を変更します。Godotで再インポートしWindowsビルドを再出力してください。配布EXEの横にPNGを置くだけでは変更されません。

v0.4.2では勇者の攻撃だけ `hero-attack-4directions.png` を使用します。上から下・上・左・右の各8コマです。各アニメーションに `texture` を指定すると、その動作だけ別PNGへ切り替わります。`scale` は動作中の最大倍率で、通常倍率から振り切り時に拡大し、終了時に戻ります。勇者は通常1.5倍、攻撃の最大2倍。足元を基準に描画し、攻撃判定や間合いは拡大しません。

| 項目 | 内容 |
| --- | --- |
| texture | `res://`から始まるPNGのパス |
| cell | 1コマの幅、高さ。現在32×32 |
| anchor | 各コマ内の足元位置。透明な余白を含めて指定 |
| scale | ゲーム内表示倍率。ドットを揃えるため整数推奨 |
| animations | アクション名に対応する横並びのコマ列 |
| row / frames / fps | 行番号（0から）・コマ数・1秒あたりのコマ数 |

例えば32×32の4コマ移動を2行目に並べたPNGなら、`animations` に `"move": {"row": 1, "frames": 4, "fps": 8}` を追加します。`idle`、`move`、`attack`、`birth` に対応。未指定アクションはidleを使用します。勇者は move_down/up/left/right と attack_down/up/left/right、look、celebrate、death に対応。loop:false で末尾のコマを保持し、mirror:false で自動反転を止めます。bonesを追加すると仮の骨描画を置換できます。

種類のキーは `sprout`（灯苔）、`beetle`（琥珀虫）、`warden`（石角）、`egg`、`knight`（戦士）、`healer`（回復役）、`heart`（主）。未登録の種類は既存アトラスへフォールバックします。新しい種類を登録すればゲーム画面・到来演出・HUDで共通して使用します。

灯苔は現在1コマです。勇者は11行の専用シートを使用しています。行とコマ数の対応は hero-v0.4.md を参照してください。

原画のピクセルは変更しません。透過部分を含むコマサイズと足元を揃え、行が画像の外へ出ないようにしてください。未知のパスでは既存絵が表示されるため、差し替え後は実画面の確認が必要です。
