# キャラクター画像の差し替え

v0.3ではユーザー自作の透過PNGを加工せず保存しています。灯苔は `assets/characters/moss-microbe-32x32.png`、戦士は `beginner-hero-32x32.png` を使用します。その他の種類は既存の仮絵です。

設定は `assets/characters/catalog.json`。PNGを同じ名前で置き換えるか、種類ごとの `texture` を変更します。Godotで再インポートしWindowsビルドを再出力してください。配布EXEの横にPNGを置くだけでは変更されません。

| 項目 | 内容 |
| --- | --- |
| texture | `res://`から始まるPNGのパス |
| cell | 1コマの幅、高さ。現在32×32 |
| anchor | 各コマ内の足元位置。透明な余白を含めて指定 |
| scale | ゲーム内表示倍率。ドットを揃えるため整数推奨 |
| animations | アクション名に対応する横並びのコマ列 |
| row / frames / fps | 行番号（0から）・コマ数・1秒あたりのコマ数 |

例えば32×32の4コマ移動を2行目に並べたPNGなら、`animations` に `"move": {"row": 1, "frames": 4, "fps": 8}` を追加します。`idle`、`move`、`attack`、`birth` に対応。未指定アクションはidleを使用します。左右は反転、上下は現在同じ絵です。方向別の原画が届いた段階で行の対応を拡張します。

種類のキーは `sprout`（灯苔）、`beetle`（琥珀虫）、`warden`（石角）、`egg`、`knight`（戦士）、`healer`（回復役）、`heart`（主）。未登録の種類は既存アトラスへフォールバックします。新しい種類を登録すればゲーム画面・到来演出・HUDで共通して使用します。

現在の2枚は各1コマです。実際の移動に合わせた補間・上下動・左右反転、攻撃時の踏み込みと軌跡、被弾色、誕生粒子で補っています。手描きの歩行・攻撃ポーズと同等の表現が完成したわけではありません。

原画のピクセルは変更しません。透過部分を含むコマサイズと足元を揃え、行が画像の外へ出ないようにしてください。未知のパスでは既存絵が表示されるため、差し替え後は実画面の確認が必要です。
